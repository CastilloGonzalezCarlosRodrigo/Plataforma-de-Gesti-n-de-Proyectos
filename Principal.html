Documentación y Ayuda

Bienvenido a la sección de Documentación y Ayuda. Aquí encontrarás información útil para utilizar la plataforma.

Funcionalidades del Proyecto

  • Formulario de Solicitudes:

    El formulario permite a los usuarios crear nuevas solicitudes. Los datos ingresados se validan antes de ser enviados al correo electrónico y almacenados en la base de datos. Los campos obligatorios incluyen: solicitante, email, fecha, centro de costos, empresa, proyecto, tipo de diseño, material y archivo adjunto.

  • Base de Datos:

    Los datos de las solicitudes se almacenan en una base de datos MySQL. La tabla principal contiene campos como solicitante, email, fecha, centro de costos, empresa, proyecto, tipo de diseño, material, archivo adjunto y estado.

  • Visualización de Datos en la Tabla:

    La tabla muestra todas las solicitudes almacenadas en la base de datos. Los usuarios pueden filtrar las solicitudes por nombre, correo o empresa, y cambiar el estado de las solicitudes directamente desde la tabla.

  • Gráficas:

    Las gráficas muestran información resumida sobre las solicitudes, como el número de solicitudes por empresa, tipo de diseño y estado.

  • Calendario:

    El calendario muestra las solicitudes en una vista mensual. Cada solicitud tiene un color diferente según su estado (verde para "Revisado" y rojo para "No revisado").

Preguntas Frecuentes (FAQ)

  • ¿Cómo crear una nueva solicitud?

    Para crear una nueva solicitud, requieres completar el formulario y enviar la información.

  • ¿Cómo cambiar el estado de una solicitud?

    En la tabla de solicitudes, haz clic en el botón de estado para cambiar entre "Revisado" y "No revisado".

  • ¿Cómo ver los detalles de una solicitud?

    Haz clic en cualquier evento del calendario para ver los detalles completos de la solicitud.
